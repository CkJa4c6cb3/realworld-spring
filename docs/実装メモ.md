#　基本的な実装の流れ
・構成はController, Model, Service, Repository
・Controllerはsrc/main/java/com/ckja/realworld/apiに生成されているinterfaceを使うこと。
　(普通はinterface作らないけど、生成されたものを活用)
・Modelはsrc/main/java/com/ckja/realworld/modelに生成されているものを使用。
・Serviceはinterface + implで実装すること

# repositoryの実装ルール

・jdbcTemplateを使用してクエリを行う。
・データの取得&Java上で使えるデータに変換するところまでを責務とする。
・戻り値はList<Entity>となるようにする。
・取得結果の変換用の処理は必要な場合は、map{Entity}Resultという名前でprivate関数化する。
